# Scribe

Scribe is a full-stack e-library platform designed to provide users with a simple and modern way to discover, read, and manage digital books.

## Key Features

- User authentication and account management
- Search and browse books from the digital catalog
- View detailed information about books
- Read books directly through the platform
- Manage a personal digital book collection
- User-specific data and protected resources
- Responsive and modern interface

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, shadcn/ui, Lucide Icons
- **Backend:** Node.js, Express.js, TypeScript
- **Database:** MongoDB

## Highlights

- Full-stack MERN application built with TypeScript
- Type-safe development across the frontend and backend
- RESTful API-based communication between client and server
- Component-based and reusable frontend architecture
- Responsive UI designed for a clean reading experience
- Authentication and user-specific library management

## Project Overview

Scribe focuses on bringing the experience of a traditional library into a digital environment. Users can discover books, access them through an online reading interface, and maintain their own digital collection in one place.

The project was built to gain practical experience in developing and structuring a complete production-oriented full-stack application using modern web technologies.
